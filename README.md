# Shibji Portfolio

Interactive React + TypeScript portfolio ready for Azure Static Web Apps.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Azure Static Web Apps

1. Push this project to GitHub.
2. In Azure Portal, create a **Static Web App**.
3. Connect the GitHub repo.
4. Use these build settings:
   - App location: `/`
   - Output location: `dist`
5. Azure will deploy automatically.
